# 디스크 I/O 도중 앱 종료·백그라운드 전환 시 보완 로직 없음

## Context
파일 탐색기 기능 확장(복사·이동·압축 내부 편집·휴지통 이동/복원)은 긴 디스크 I/O를 수행한다.
정상적인 쓰기 실패는 임시 결과를 완성한 뒤 교체하는 방식으로 원본을 보존하지만, I/O 도중 프로세스가
사라지거나 작업이 중단되는 경우의 보완 로직은 해당 기능 범위(spec `878368af3a25f02c`, Out of scope)에서 제외되었다.

## Uncovered Situations
- 앱 강제 종료 또는 시스템에 의한 프로세스 종료.
- 앱 최소화, 화면 꺼짐 등으로 백그라운드에 들어가 작업이 중단되거나 프로세스가 회수되는 경우.

## Risks
- 압축 파일 교체 직전·도중 종료 시 원본 또는 임시 결과가 남거나 불완전한 상태가 될 수 있다.
- 이동 작업에서 복사 완료 후 원본 삭제 전 종료 시 중복이 남고, 반대 순서의 불일치 가능성을 점검해야 한다.
- 휴지통 이동·복원 중 종료 시 파일과 메타데이터가 어긋날 수 있다.
- 남은 임시 파일이 정리되지 않는다.

## Next Step
백그라운드 전환 시에도 작업이 이어지거나 안전하게 중단되도록 실행 방식을 정하고, 재시작 시 미완료 작업과
임시 파일을 감지해 롤백 또는 재개하는 복구 로직을 구현한다.
