# Hilt 의존성 주입

Status: Accepted

## Decision
- 의존성 주입은 Hilt로 한다. Application은 `@HiltAndroidApp`, ViewModel은 `@HiltViewModel`을 쓴다.
- 바인딩 모듈은 해당 core 모듈(`core/data`, `core/database`) 안에 둔다.

## Alternatives
- 수동 DI(Application이 보유한 container): 모듈 수가 늘면 생성 코드와 ViewModel factory를 직접 유지해야 해서 기각했다.

## Consequences
- Positive: 테스트에서 `@TestInstallIn`으로 fake repository를 바꿔 끼울 수 있다.
- Negative: KSP 코드 생성으로 빌드 시간이 늘고, Hilt/KSP 버전을 AGP·Kotlin 버전과 맞춰야 한다.
