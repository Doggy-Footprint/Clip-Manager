## Setup

1. Start/cold-boot the `clip_tablet_1280x800` AVD (API 35).
2. Install the built debug APK (`./gradlew :app:assembleDebug`, then install the resulting
   `app-debug.apk`).
3. Seed shared storage with one file per viewer target before opening the app:
   - a video file with a video-container extension (e.g. `.mp4`),
   - an image file (e.g. `.jpg`),
   - an audio file (e.g. `.mp3`),
   - a `.pdf` file with at least one page,
   - a `.txt` file with known UTF-8 text content,
   - a `.cbz` file containing at least two image entries in a known name order (for the
     manga viewer) and reachable as a plain folder-of-images via the CBZ tab's `폴더로 열기`
     menu item (R6/V4 row 6).
4. R15/A12 (spec v4): path-less MediaStore URI items are hard to reproduce naturally on the
   API 35 AVD (MediaStore backfills `DATA`), so reproduce them with the debug-only settings
   toggle `경로 없는 미디어로 취급` instead of inserting into MediaStore directly. Turn the
   toggle on before V4 row 7 and before V10; a normal video/image already visible in the
   Videos/Images tab is then treated as path-less (`filePath == null`) for the rest of the
   session. This toggle only exists in debug builds (R15) - do not expect it in release.
